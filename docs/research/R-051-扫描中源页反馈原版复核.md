# R-051 扫描中源页反馈原版复核

状态：已复核（本机原版截图逐像素读取）；结论要求修改 ADR-0027 第 2 条

日期：2026-08-25

## 1. 问题

[ADR-0027](../adr/0027-DaisyDisk扫描中窗口状态边界.md) 第 2 条要求：

> 扫描中的源页必须持续展示当前磁盘行、阶段、不确定进度条、已处理节点/文件、文件树占用、已用时和取消动作。

该条的依据是 R-025/R-014 的"本机复核"，但那两份记录没有留下扫描中源页的截图证据，"已处理节点/文件、
文件树占用、已用时"这四项是否真的出现在原版的源页上，从未被逐项核对过。

本轮实施 UI 复刻时按该条实现，得到的源页与原版差距明显：原版一行，我们多出一整块进度面板和第二个、
第三个取消按钮。因此先复核原版到底显示什么，再决定改代码还是改 ADR。

## 2. 环境与方法

本机同机原版 DaisyDisk 截图（`~/Downloads/daisydisk截图/`），Retina 2x：

- `xw_20260825112942.png`（`2586x304` 物理 = `1293x152` 逻辑）：已有扫描结果的空闲态；
- `xw_20260825113207.png`（`2576x304` 物理 = `1288x152` 逻辑）：**扫描进行中**；
- `xw_20260825113148.png`：空闲态展开的行菜单。

几何按图像像素读取后除以 2 换算为逻辑 px，百分比按窗口逻辑宽度计。

## 3. 证据

### 3.1 原版扫描中源页只显示一条"扫描中…"

`xw_20260825113207.png` 上出现的全部元素：

| 元素 | 内容 |
| :-- | :-- |
| 卷图标 | 磁盘图标 |
| 卷名 | `Macintosh HD` |
| 副标题 | `245.1 GB 加密的启动盘`（**与空闲态完全相同，不换成扫描信息**） |
| 进度条 | 条纹不确定条，浅蓝虚线，占轨道约 `36%` |
| 进度条下方 | `扫描中...`，灰色，**左对齐到轨道左端** |
| 按钮 | `取消`（单按钮，无 chevron） |
| 底部 | `扫描文件夹...`（左）、`扫描云存储 ▾`（右），与空闲态相同 |

**没有出现**：阶段名、已处理节点数、文件数、文件树占用、已用时、第二个进度条、第二个取消按钮。
窗口高度在扫描前后都是 `152` 逻辑 px，骨架一格没变。

### 3.2 窗口高度与 R-014 一致

两张图都是 `152` 逻辑 px 高（标题栏 `52` + 卷行 `48` + 底部 `52`），与 R-014 记录的"启动入口约
968 x 151"一致。我们此前用的 `258` 高没有出处，那块空白就是它。

### 3.3 计量条的几何（空闲态与扫描态相同）

以窗口逻辑宽度为基准：

| 元素 | 左 | 右 | 宽 |
| :-- | --: | --: | --: |
| 计量条轨道 | `68%` | `92%` | 约 `310px`（`24%`） |
| 操作按钮 | `94%` | `99%` | 约 `65px` |
| 卷名/副标题 | `6%` | 自适应 | — |

轨道高约 `4px`，圆角，轨道底色深灰，空闲态填充亮橙红。轨道**不是全宽**，也不在名称下方——这是我们
此前版式最大的结构性偏差。

### 3.4 条下文字的对齐方式在两态不同

- 空闲态：剩余空间 `13.2 GB`，**右对齐**到轨道右端，橙色；
- 扫描态：`扫描中...`，**左对齐**到轨道左端，灰色。

这不是笔误，两张图分别测得，差异明确。

## 4. 结论

1. ADR-0027 第 2 条中的"已处理节点/文件、文件树占用、已用时"**在原版源页上不存在**。该条把 Marmot
   自己的诊断需求写成了"与原版一致"的要求，属于无证据条款，和 R-047 里 `<15s`、R-049 里 `256 KB`
   同类；
2. "阶段"也不显示：原版扫描全程只有一句 `扫描中...`，不随阶段变化；
3. 必须保留的是：卷行、不确定进度条、取消动作——这三项原版确有，且 ADR-0027 的其余部分（不提前切页、
   进度条不伪造总量、终态才查 Map）不受影响；
4. 计量条的位置、宽度和条下文字的两态对齐方式按第 3.3/3.4 节实现。

产品决策由用户给出：**扫描页要与原版一致**。据此提 [ADR-0050](../adr/0050-扫描中源页反馈与原版一致.md)
取代 ADR-0027 第 2 条。

## 5. 限制

- 只覆盖源页。结果页的进度/状态表达不在本轮范围；
- 原版条纹段占轨道约 `36%` 而非全宽，无法从单帧判断它是真实进度还是动画的某一帧。因此本轮**不据此
  推断原版知道总量**，Marmot 继续按 ADR-0027"不伪造总量"用滑动条纹表达不确定；
- 未复核多卷（外接盘）同时在列时的行高与窗口高度变化。
