# R-016 DaisyDisk 视觉版式与窗口状态基线

状态：已完成，结论由 ADR-0018 接受

日期：2026-08-20

## 1. 目的

R-014 已确认 DaisyDisk 的交互行为，但当前 Marmot 仍是网页式工作台：启动页有 Hero、卷卡片和状态区，
结果页有地图面板、Inspector 和横跨底部的 Dock。它们虽然能承载功能，却没有复现原版的窗口层级和视觉节奏。
本预研把原版截图、本机可逆操作记录和当前 DOM 结构转换为可验收的版式约束。

## 2. 对照证据

- R-014：本机启动入口约 968 x 151，结果窗口约 968 x 715；结果页由 Sunburst、当前目录列表和左下
  Collector 组成。
- 当前 Marmot 启动 DOM：`workspace-head -> volume-strip -> scan-controls -> empty-workspace -> collector-dock`，
  仍是 Dashboard 结构。
- 当前 Marmot 结果 DOM：`status-strip -> breadcrumb -> map-panel -> directory-panel -> collector-dock`，
  右侧 `directory-context` 仍承担 Inspector 的常驻视觉重量。
- 附件中的原版启动图和结果图：启动窗口是紧凑卷行，结果窗口是连续的深色桌面工作区。

## 3. 采用的视觉结构

### 3.1 启动态

启动态是紧凑的卷选择窗口，不展示结果工作区的解释性卡片：

```text
窗口工具栏：Marmot / 权限状态                         试用 / 购买
卷行：图标 + 卷名/容量 + 使用进度 + 查看(下拉)或扫描
操作栏：扫描文件夹…                                   扫描
```

- 内容宽度目标为 760 px，内边距 28 px；窗口不使用 Hero、营销式大标题或常驻 Collector。
- 卷行高度 64-78 px，使用进度条直接位于卷名下方；卷名、容量和权限状态优先于技术字段。
- 已有结果时主按钮显示“查看”，下拉菜单至少保留“查看、重扫、放弃当前结果”三个动作；没有结果时
  主按钮显示“扫描”。
- “扫描文件夹…”仍调用 Wails 原生目录选择，不在页面中实现文件系统浏览器。
- 启动态允许窗口高度随卷数量增长，但第一屏保持紧凑，不出现旧版 `READY TO SCAN` 大块空状态。

### 3.2 结果态

结果态是单一连续工作区，不再使用页面卡片拼接：

```text
顶部：后退 / 前进 / 返回上一级 / 分段面包屑 / 当前扫描状态
主体：左侧 Sunburst（约 68%） | 右侧当前目录列表（约 32%）
左下：紧凑 Collector 投放区；展开内容使用局部浮层
```

- 结果工作区占满可用高度，背景使用中性深灰，不使用绿色 Dashboard 主色或大面积边框卡片。
- Sunburst 是第一视觉主体，直径目标为工作区高度的 72%-88%，中心圆显示当前目录名称和总大小。
- 右侧只显示当前目录标题、总大小、按 `owned_allocated` 排序的直接子项和必要的状态标记；
  不把 Inspector 卡片作为右侧主栏。
- `hoveredEntry`、`focusedEntry` 和 `selectedEntry` 继续保留，但对象动作只以窄的上下文条或浮层出现，
  不能挤压当前目录列表的主空间。
- Collector 固定在结果工作区左下角，默认是小型虚线投放区；打开后从左下方展开，不横跨整个窗口底部。

## 4. Sunburst 视觉参数

- 保留后端有界多层 `children` 投影，不重复绘制当前层，也不为每个扇区发起 Wails 查询。
- SVG 使用稳定的 600 x 600 视口；中心半径目标 52-64，环厚目标 42-50，环间隙 2-4。
- 最多绘制 5 个投影深度；同一根目录分支继承色相，外层通过亮度/透明度区分深度。
- 真实节点使用实心扇区；`aggregate`/`virtual` 使用灰度、低饱和度和虚线边界，不能伪装成文件夹。
- 悬停只提升亮度和焦点边界；选中使用白色窄边界；过期/部分结果降低饱和度但保留空间比例。
- 投影截断、部分结果和大小口径放在轻量状态提示中，不在图中央增加说明卡。

## 5. 不变的行为和安全边界

- 目录单击下钻、文件单击选中、中心圆返回、有限历史和键盘操作仍按 ADR-0016 执行。
- 目录列表和 Sunburst 必须使用同一个 `MapResult`；列表不能从前端完整树重建。
- Collector 仍只是会话候选，清理计划必须重新校验，默认移入 macOS 废纸篓。
- 本记录只冻结布局与视觉状态，不复制 DaisyDisk 的品牌、素材、源码、永久删除行为或授权流程。

## 6. 验收标准

1. 无扫描结果时，首屏是紧凑卷行和扫描入口，不再出现大块工作台空状态和常驻 Collector。
2. 有扫描结果时，首屏同时呈现 Sunburst、右侧当前目录列表和左下 Collector，页面没有常驻 Inspector 卡片。
3. 结果窗口在 968 x 715 附近时，Sunburst 与右侧列表均不出现滚动条遮挡、内容重叠或布局跳动。
4. Sunburst 至少能显示有界真实多层环；投影截断时保留聚合语义并显示部分状态。
5. 目录列表和 Sunburst 的悬停、焦点、选中、进入和返回行为保持 ADR-0016 的契约。
6. 纯前端悬停和焦点操作不产生 Wails 调用；生产通信仍只有类型化绑定和事件。

## 7. 限制

- 本记录锁定 Marmot 的版式目标，不声称复制 DaisyDisk 的私有实现或像素级品牌素材。
- 原生 Wails 窗口的真实圆角、标题栏和签名/TCC 行为仍需 macOS 打包 smoke test；CSS 只负责 WebView 内容区。
- 试用/购买按钮只保留产品层级占位，不进入支付或授权实现。

## 8. 建议

接受 ADR-0018，整体替换当前前端版式样式，保留现有领域、Wails 契约和交互状态逻辑。
