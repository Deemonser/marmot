# ADR-0009 清理计划与 macOS 废纸篓执行

状态：Accepted（跨卷和发布签名环境仍需 smoke test）

日期：2026-08-19

## 背景

扫描快照会过期，文件可能被替换、移动或通过硬链接共享。清理必须是独立、可审查、可
重新校验的流程，不能把扫描结果直接当成删除授权。

## 预研依据

- [R-005 清理安全与恢复](../research/R-005-清理安全与恢复.md)
- macOS Foundation `FileManager.trashItem(at:resultingItemURL:)`

## 决策

- 计划保存来源快照、计划版本、策略版本和每个清理项的路径/卷/身份/大小/时间；
- 创建、确认和执行前均重新校验；每项执行前再次校验 `lstat` 身份；
- 父子项重叠时默认拒绝计划，不能静默扩大或缩小用户选择的删除范围；
- 平台适配器使用 Foundation Trash API，不调用 Shell 删除或拼接路径命令；
- 默认允许普通文件、目录和显式选择的符号链接；拒绝特殊文件、卷根和扫描根；
- 每项返回独立状态，支持部分成功；重复执行已完成项必须是幂等的；
- 不承诺多项操作原子回滚，恢复交给 macOS/Finder 废纸篓；第一阶段不永久删除、不安全擦除。

## 后果

清理执行结果不能回写为扫描事实，执行后需要提示用户刷新或重新扫描。跨卷废纸篓、空间
不足和崩溃恢复需要在真实签名应用中继续验证。
