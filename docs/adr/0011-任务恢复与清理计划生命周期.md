# ADR-0011 任务恢复与清理计划生命周期

状态：Accepted

日期：2026-08-20

## 背景

扫描和清理都跨越较长时间，进程退出后如果没有明确语义，系统可能把部分扫描伪装成完整
结果，或自动恢复过期的清理计划。两者都涉及用户信任和文件操作安全。

## 预研依据

- [R-008 任务恢复与清理计划生命周期](../research/R-008-任务恢复与计划生命周期.md)
- [R-005 清理安全与恢复](../research/R-005-清理安全与恢复.md)
- [ADR-0003 全盘扫描与快照架构](0003-全盘扫描与快照架构.md)
- [ADR-0009 清理计划与 macOS 废纸篓执行](0009-清理计划与macOS废纸篓执行.md)

## 决策

- 第一阶段不支持跨进程续扫；进程退出时，仍为运行中的扫描任务在下次启动恢复为
  `interrupted`，已提交节点保留为部分快照。
- 重新扫描创建新的任务和快照，不复用旧任务 ID。
- 窗口隐藏或 Dock 重开只要进程仍在，继续使用现有任务和会话状态。
- 第一阶段清理计划是会话内对象；进程退出后不自动恢复、确认或执行旧计划。
- 跨进程清理计划恢复必须新增 ADR，不能通过 localStorage、旧 JSON 或默认值隐式实现。

## 后果

- SnapshotStore 和应用启动编排需要处理未完成扫描的收尾状态。
- 用户可以看到已提交的部分结果，但不能把它误认为完整扫描。
- 实现简单且不会自动扩大文件操作范围；代价是进程退出后需要重新扫描，清理计划需要重新创建。
- 真实崩溃、强制终止和多次启动验证仍是发布门禁。
