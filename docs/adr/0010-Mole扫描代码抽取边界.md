# ADR-0010 Mole 扫描代码抽取边界

状态：Accepted

日期：2026-08-19

## 背景

Mole `V1.40.0` 的扫描器包含受限并发、硬链接去重、批量发布和缓存经验，但源码属于
`package main`，并混合 CLI、TUI、`du`、Spotlight、缓存和清理逻辑。

## 预研依据

- [R-002 Mole 能力与许可证](../research/R-002-Mole能力与许可证.md)
- [ADR-0005 复用 Mole V1.40.0 的 MIT 代码](0005-复用Mole-V1.40.0的MIT代码.md)
- 固定提交 `c3ef1f50ea7a2490957dd8cbffadfcc350dd1182` 的本机抽取编译和测试

## 决策

- 可选择性复制或改造 `scanLimiter`、目录遍历、取消发布边界、硬链接去重和 Top-N 堆；
- 这些代码必须改为 Marmot Infrastructure 包，输出映射到 Marmot 自己的 `ScanNode` 和端口；
- 不复制 Bubble Tea TUI、Mole JSON、Shell/`du`/`mdfind` 编排、Mole 缓存格式和清理逻辑；
- APFS clone metadata、SnapshotStore、权限模型和清理计划由 Marmot 自己实现；
- 每次导入记录精确提交、文件来源和 MIT notice，并单独审查依赖许可证。

## 验证结论

将 `scanner.go`、`constants.go` 和 `heap.go` 抽到独立临时包后，补充 Marmot 节点类型和
缓存/路径校验端口即可编译，并通过硬链接去重扫描测试。说明抽取可行，但不是直接复制即
可用的生产模块。
