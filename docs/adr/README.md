## 流程

```text
技术预研
  -> ADR 提出
  -> 评估方案和代价
  -> ADR 接受
  -> 更新 SDD / DDD / README
  -> 实施
```

没有证据的假设不能直接写成 Accepted 决策。

## 状态

- `Proposed`：讨论中，不能作为实施依据。
- `Accepted`：已锁定，必须按此实施。
- `Rejected`：已评估但不采用。
- `Superseded`：被后续 ADR 替代。

## 规则

- 接受后的 ADR 原则上不修改，用新 ADR 替代旧决定。
- 每个 ADR 必须链接相关预研记录。
- 接受后同步更新 SDD；领域规则变化时同步更新 DDD。
- 使用四位数字和短横线命名，例如 `0002-cleanup-plan.md`。

新增决策使用 [ADR 模板](0000-template.md)。
