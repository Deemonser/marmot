# ADR-0030 应用持久化队列上限与终态内存

状态：Accepted

日期：2026-08-24

实施状态：代码切片已完成；真实 `/` 三次复测完成，15 秒总门槛仍未达到

## 背景

ADR-0028/0029 已确定原生批量扫描和追加式二进制快照，但 Application 的 `runScan` 将
`scanBatchSize=50000` 同时用于 writer 聚合阈值和事件 channel 容量计算：

```go
events := make(chan persistEvent, scanBatchSize*2)
```

这会创建 `100000` 个事件槽位，与 SDD 的待提交批次 `2` 不一致。扫描和持久化速度短暂不平衡时，
大量节点批次可能滞留在 Go 堆中，放大 RSS 和终态抖动。

依据：[R-028](../research/R-028-应用持久化队列上限与终态内存预研.md)、
[ADR-0028](0028-macOS原生扫描与追加式二进制快照.md)、
[ADR-0029](0029-macOS原生扫描资源复用与性能切片.md)。

## 决策

### 1. 固定 Application 持久化事件队列容量

新增 `scanPersistQueueCapacity = 2`，`runScan` 使用该常量创建持久化事件 channel。该容量是待消费
事件批次数，不是节点数，也不是 SnapshotStore 的节点提交批次大小；不开放用户配置。

### 2. 分离两个批次概念

保留 `scanBatchSize=50000` 作为 writer 在 Application 内聚合节点后提交给 SnapshotStore 的阈值。
后续修改提交批次必须单独评估，不得通过改变 `scanBatchSize` 间接扩大事件队列。

### 3. 保留受控背压和顺序语义

- 事件队列满时，发送端在 `context` 可取消的 select 中等待；
- writer 消费事件后发送端继续，不能丢弃节点或静默降级为不落盘；
- writer 发生错误或提前退出时，发送端收到错误并停止扫描；
- barrier 事件保持 FIFO，确保首层发布前的节点已由 writer 刷入 SnapshotStore；
- 取消、部分结果、footer、校验和、Sync、manifest 原子发布和查询契约保持 ADR-0028 的定义。

## 不采用的方案

- `scanBatchSize*2`：容量随提交批次线性放大，无法表达稳定内存预算；
- 无缓冲 channel：缺少当前证据，可能增加扫描与持久化的同步抖动；
- 丢弃旧节点或只保留汇总：违反快照事实完整性和清理安全边界；
- 关闭 Sync/校验或改用第二套内存树：超出本 ADR 范围并破坏既有恢复语义。

## 后果

正面后果：

- 将 Application 等待中的事件上限从 `100000` 明确收紧为 `2`；
- 扫描和 writer 之间形成可解释、可取消的背压，降低节点切片长期滞留造成的峰值 RSS；
- 不改变 Wails、SnapshotStore、快照格式、领域模型和清理边界。

代价和风险：

- writer 短暂变慢时，扫描线程会更早等待，纯扫描耗时可能上升；
- 需要用同条件真实 `/` 测量确认完整终态收益，而不能依据代码审查推断性能提升；
- 若仍未达到 15 秒，必须用新的分段 profile 选择下一项优化。

本轮三次真实 `/` 完整终态为 `20.504s`、`25.731s`、`20.895s`，中位数 `20.895s`；
`FinishSnapshot` 为 `4.054s`、`4.127s`、`4.112s`，最大 RSS 为 `611,942,400`、
`619,282,432`、`611,860,480` 字节。节点数均为 `2,846,083`，问题数为 `441/443/441`。
该结果确认实现和内存上界语义已落地，但没有证明队列是 15 秒目标的主瓶颈。

## 验收标准

- 事件 channel 容量由 `scanPersistQueueCapacity` 固定为 `2`；（已完成）
- scanner、snapshot、application 测试及相关 race 测试通过；
- 取消、writer 错误、首层 barrier、问题记录、分页/Map 查询和快照恢复无回归；
- `go vet ./...`、前端构建和 `git diff --check` 通过；
- 真实 `/` 三次记录纯扫描、完整终态、RSS、节点/问题数和 `FinishSnapshot`；（已完成）
- 只有完整可查询终态中位数 `<=15s` 才能关闭当前总性能目标。
