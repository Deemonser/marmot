# ADR-0045 Darwin 原生扫描回调锁争用削减

状态：Accepted

日期：2026-08-24

实施状态：已实施；完整终态性能子目标达成，次级回退对照受基线限制

## 背景

R-044 实施后，真实 `/` 完整终态中位数为 `34.15s`。mutex profile 显示
`nativeScanContext.addNodes` 约占 mutex delay 的 `98.7%`，争用等待约 `1.046s`。当前实现把每批路径构造、
节点转换、硬链接查找和目录汇总都放在全局锁内，多个原生 worker 会在 cgo 回调入口排队。

依据：[R-045](../research/R-045-Darwin原生扫描回调锁争用削减预研.md)、
[R-044](../research/R-044-FinishSnapshot关系归并直接消费预研.md) 和
[ADR-0028](0028-macOS原生扫描与追加式二进制快照.md)。

## 决策

### 1. 批次转换移到锁外

`addNodes` 先在短锁内按 raw batch 顺序读取每个 parent 的 path 字符串并校验 parent 存在；释放锁后完成
路径拼接、Name 复用、节点字段转换和大小可信度计算。所有节点路径必须复制到 Go backing buffer，不引用 C
批次内存。

### 2. 每批一次状态合并

转换完成后重新加锁一次，仍按 raw batch 顺序更新硬链接 `seen` 和目录状态；目录大小增量在锁外按 parent
聚合，锁内每个 parent 只合并一次，再更新批次级 `scan.Result`；然后释放锁并调用 emitter。共享状态的所有权
不变，只缩短锁持有范围。

### 3. 保留原有并发与发布边界

不改变 worker 数量、批次上限、ID 分配、父子关系、挂载边界、fd/openat、取消、issue、SnapshotStore、数据帧
校验、index/manifest 发布、恢复和 Wails 契约。DDD 不变，不新增公共接口或配置。

## 不采用的方案

- 使用 `sync.Map` 或无锁目录状态：会引入新的状态访问协议和类型转换成本，本轮只需缩短临界区。
- 每 worker 独立硬链接/目录状态：会改变全局去重和父目录汇总语义，需要新的合并契约。
- 取消去重或汇总：会破坏空间占用事实。

## 后果

正面后果：

- 路径拼接和节点构造不再阻塞其他 worker 的回调状态合并；
- emitter 背压不会持有扫描状态锁；
- 保留现有有界 map、硬链接去重、目录汇总和批次语义。

代价和风险：

- 每批会有一份 parent path 快照和准备中的节点 slice；它们随批次大小有界，并在 emitter 返回后释放；
- 每批会额外保留有界的 parent 目录大小增量 map，硬链接判定后再合并到全局目录状态；
- parent 缺失、并发取消和 emitter 错误必须在两段式流程中保持一致；
- mutex 等待降低不等于完整终态必然达到 `15s`，必须用同口径真实 smoke 验证。

## 验收标准

- 扫描器批量、取消、挂载边界、队列满载、硬链接、目录汇总和快照回归通过；相关 race、全量测试、vet 和前端
  构建通过。
- 真实 `/` 串行三次相对 R-044 的完整终态中位数降低至少 `10%`，纯扫描、`FinishSnapshot`、节点/问题、查询、
  checksum、恢复和最大 RSS 无超过 `3%` 回退。
- 产品完整终态 `15s` 仍独立验收。

## 实施结果

配置扫描器回归、相关 race、全仓 Go 测试、`go vet`、前端构建和差异检查已通过。真实 `/` 三轮完整终态为
`26.691s`、`28.961s`、`23.266s`，中位数 `26.691s`；`FinishSnapshot` 中位数 `4.723s`，相对 R-044
完整终态中位数 `34.15s` 下降约 `21.8%`，完整终态性能子目标达成。纯扫描三轮中位数为 `21.645s`；最新
mutex profile 总等待约 `479.56ms`，`addNodes` 约 `456.28ms`。一次 RSS 测量为 `440,795,136` 字节。

R-044 未记录可比的纯扫描三轮和最大 RSS 基线，因此次级 `3%` 回退门禁保留为未完全比较；产品完整终态
`15s` 仍未达成。

## 与既有决策的关系

补充 ADR-0028/0029 的 Darwin Infrastructure 性能边界，继承 R-040/0041 的路径与目录状态所有权；不改变
R-043/0044 的 SnapshotStore 关系索引方案，也不改变 DDD、SDD 公共端口、Wails DTO 或 DaisyDisk 交互。
