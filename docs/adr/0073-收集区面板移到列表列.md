# ADR-0073：收集区面板移到列表列

- 状态：Accepted（2026-09-09 使用方在两方案比较后答复「选择方案二，但是依然去掉收集列表的高度上限」）
- 日期：2026-09-09
- 相关预研：[R-075](../research/R-075-收集区面板位置的几何复核.md)
- 关系：
  - **取代 [ADR-0066](0066-建议与收集区合并为一个面板.md) §1 的位置**（"左下一个面板"）与**第二次修订的几何**
    （左边距 33px、宽为地图列 62% 减 17px）。ADR-0066 §2-§6 与"一套几何、折叠只改高度"的原则不变。
  - **不修改 [ADR-0018](0018-DaisyDisk视觉版式与窗口状态重做.md)** 的主区域比例基线：空间图仍在左、列表仍在右，
    只在面板展开时列表列临时放宽。
  - **不修改 [ADR-0059](0059-空间图配色模型与层级几何.md)** 的轮盘几何：直径由高度决定，列宽变化不影响它（R-075 §3）。

## 背景

面板展开时盖满左侧空间图列，这是 ADR-0066 第一次修订按使用方要求定的。但 ADR-0066 §3 同时要求收集区行悬停时
对应的弧呼吸，面板盖住的正是那些弧——刚修好的呼吸（`8a4a623`）在面板打开时看不见。已收集列表限高 `26vh` 也是
同一个原因：它与"待确认"区争同一列的高度。而"待确认"区已随勾选式收集区（`31c001c`，行带勾选框、只有勾上的进
计划）消失，`26vh` 失去了存在的理由。

## 预研依据

R-075 §2：轮盘底边在动作条之上 57 px，窗口两个底角都在圆之外；§3：列表列放宽到 46% 是不动轮盘直径的最大值，
面板得 381 px；§4：徽标骑面板左下角、悬出 22 px 进空间图列，不与轮盘相交，镜像到右下角会悬出窗外；§5：去掉
`26vh` 后折叠动画不受影响。

## 方案

### 方案一：扇区右、列表左，面板留在左下盖列表（拒绝）

扇区可见、联动可见，但与原版左右相反，ADR-0018 逐像素量的几何要重做，左列要扩到 45% 才放得下面板，
扇区缩小约一成。为解决遮挡把主角搬走。

### 方案二：扇区留左、列表留右，面板移到右下盖列表列，展开时列表列放宽到 46%（采用）

扇区与列表位置与原版一致，面板盖的是列表（一个列表盖另一个列表，形状一致），扇区完整可见。代价是徽标离开
原版的左下角、"分析优化"按钮换到左下。

## 决策

### 1. 面板在列表列下方，右缘贴 16 px 页边距

`.collector-dock { right: 16px; bottom: 24px }`。徽标仍骑面板左下角（圆心在左缘内 3 px，悬出 22 px），面板与列同宽、
左缘与列边界重合，悬出落在空间图列内、轮盘之下。

### 2. 面板展开时列表列放宽到 46%

`.app-shell.is-dock-open .has-result .workbench { grid-template-columns: 54fr / 46fr }`，240 ms 过渡；`is-dock-open`
即"有收集项且面板展开且未锁定"。面板在**所有状态**取同一宽度 `(100vw − 32px) × .46`：展开时移动的是列边界，
面板与徽标不动（ADR-0066 修订的原则）。只剩动作条时它向左伸进空间图列 8%，那里在轮盘之下，是空的。

### 3. 已收集列表没有自己的上限

去掉 `.collector-list { max-height: 26vh }`；`.dock-staged` 改为 `flex: 1 1 auto; min-height: 0`。面板顶到面包屑之下
（`max-height: calc(100vh − 54px)` 不变），列表拿面板给的全部高度并在其内滚动。折叠仍是网格行 `1fr → 0fr`，
起点是列表的真实高度。

### 4. "分析优化"按钮移到左下角

`.advice-corner { left: 22px }`，与面板对角。它在轮盘之下的空角里（R-075 §2）。

### 5. 不变的东西

- 空间图左、列表右；轮盘直径与位置；徽标三态与声呐；动作条的顺序（徽标、文字、删除）与胶囊底板；
- 收集、勾选、删除、倒计时的逻辑一律不动；
- 悬停联动（ADR-0066 §3）不变——现在它可见了。

## 后果

正面后果：

- 面板打开时轮盘完整可见，悬停联动有了意义；
- 已收集列表能伸到顶，长列表不再挤在 26vh 里；
- 扇区与列表保持原版位置。

代价和风险：

- 面板宽从 510 px 降到 381 px，长名字上标签会截断；
- 徽标不在原版的左下角；
- 列宽过渡是否顺滑、面板只剩动作条时伸进空间图列 8% 的观感，待真实窗口验证；
- 820 px 断点以下的单列规则只改了锚点，未重算。

## 验收门禁

1. 前端 `tsc`、`vite build`、单测无错误；
2. 真实窗口：面板展开时轮盘完整可见，悬停收集区行时对应弧呼吸；列表超过面板高度时在面板内滚动，面板顶到
   面包屑之下；折叠时只有高度在动，徽标与面板左右边不跳；
3. 徽标与轮盘不相交；"分析优化"按钮与轮盘不相交。
